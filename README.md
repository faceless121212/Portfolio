# Portfolio · Illia Ladyha

This repository holds my personal portfolio website as a Product Manager focused on growth, onboarding and activation.

**Live site:** https://faceless121212.github.io/Portfolio/

## What's inside

- **Case studies** from my product work in consumer apps, fintech, payments and EdTech. Each one walks through the problem, discovery, hypotheses, decisions, execution and lessons learned.
- **Products I've built** with AI as part of the team, from first idea to working product.
- **How I work:** the principles I follow as a product manager.
- **About and contact**, with a downloadable resume.

## About the project

The portfolio is treated as a product in its own right: clear, fast and easy to scan.
It's a static website built with plain HTML, CSS and a little JavaScript. It works on mobile, follows accessibility basics and is published with GitHub Pages.
The illustrations and hero animation were created with generative AI.
